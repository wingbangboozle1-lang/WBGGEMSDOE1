Auditable method

One lane.
Every gate.

The experiment separates physical scoring, spatial validation, registry comparison, file validation and slot governance. Passing one never implies passing the next.

TIP1 physical operator

The detector uses only the SHA-pinned USGS 3DEP-derived 100 m LiDAR aggregate stack. It reads step_max, positive and negative curvature, coh100, axial strike, opposing face gradients, cross_max and valid support. It never reads the fault catalogue or an older prediction.

For each supported cell, coherence is sampled at ±2 and ±4 integer cells along that cell's own axial bearing. The fixed primary is:

Arm B = max(|coh(+2)−coh(−2)|, |coh(+4)−coh(−4)|) × balanced curvature × √step × channel-bank veto.

Balanced curvature is 2√(lapneg·lappos)/(lapneg+lappos+ε). The smooth channel veto is max(upface,downface)/(max(upface,downface)+cross). Both sampled endpoints must have complete support, preventing missing-LiDAR edges from acting as tips.

Spatial holdout

The shared SegmentHoldout labels 8-connected catalogue components and partitions the footprint into four spatial quadrants. Any component touching validation or its 1.5 km collar is hidden everywhere. TIP1 is catalogue-independent, so there is no fold-dependent catalogue feature to rebuild. Emission masks each fold's visible catalogue pixel-exactly.

  • Fixed fold budget: 0.73% of valid cells
  • Poisson minimum spacing: 3 pixels
  • Metric: pooled TPw/FPw/FNw, never mean fold ratios
  • α = 0.2; β = 0.8; triangular credit radius = 300 m
  • 95% interval: 1,999-draw percentile bootstrap over 10 km spatial blocks
  • Withheld positives: 60,988

Leakage and novelty

Every one of 29 raw, decoded and transformed descriptors—including each final arm—is tested alone with pooled and per-fold AUC in both polarities. Any extremity above 0.90 stops the lane.

The registry starts with 231 immutable sources across all nine focus repositories, verifies Git object identity and every available SHA-256, checks the competition grid and exact float32 footprint content, then deduplicates to 179 unique rasters. Surface Spearman is exact over all 5,167,373 footprint pixels; the kernel sensitivity sample is fixed at 200,000 cells. Final overlap is directional over every candidate dot within an inclusive 3-pixel radius.

A documented shared-tool fix stores restore-time-validated compact comparator arrays and evaluates all fixed surfaces in one registry pass. This changes no threshold or statistic; tests prove equivalence to exact Spearman and overlap.

Emission and file writing

priority_poisson sorts the new physical surface deterministically and adds no zero-score backfill. The caller excludes public catalogue pixels. The shared writer copies the exact template profile, writes one float32 band, and uses finite zero exterior cells to avoid whole-array range rejection. The shared validator checks the official grid, count, dtype, CRS, transform, footprint finiteness/range and the strict whole-array [0,1] variant.

Governance

Arm B was fixed before code. Arms A and C are controls and cannot replace it after results. The run limit was three experiments or two hours. Promotion required a point win over S3DEP1 and a strictly positive paired 95% CI from an independent replay. Replay material was unavailable, so that gate failed closed regardless of the point result. Upload is a separate selector action; this project spent zero slots.
