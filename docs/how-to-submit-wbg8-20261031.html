Exactly how to submit — WBG-8 candidate

File: wbg8-mridge-pois300-offcat3-37654-20261031-1cfe8cc8-zeros.tif (or .zip) — verdict OK TO DOWNLOAD & SUBMIT, validator ok_to_submit: true, sha256 8adb3dbc89bd15e31312bf9e09df47a39447f4319a47141b15d7b18cfd9c5150.

  1. Download the .tif (single-band GeoTIFF) or the .zip (exactly one GeoTIFF inside, byte-identical). Do not re-export or convert it in a GIS first — re-exporting changes bytes and can push values outside [0,1].
  2. Verify the hash (optional): sha256 8adb3dbc89bd15e31312bf9e09df47a39447f4319a47141b15d7b18cfd9c5150. It must match the run card.
  3. Go to DrivenData → Competition 306 → Submission (owner login; this repo never stores credentials).
  4. File to submit: pick the downloaded .tif (or .zip). Format rules from the rules PDF and problem page: single-band float32 GeoTIFF, EPSG:32611, 3730×3292, 100 m grid, values in [0,1]. All verified by scripts/validate_submission.py (15/15 checks PASS + template report PASS; receipt preflight.json and validator.json — the writer receipt's 10/10 hard checks and the strict whole-array [0,1] check pass; its 3 soft NaN-compatibility checks fail by design because this file uses the portal-safe all-finite zeros exterior instead of NaN).
  5. Note (paste this): WBG-8 blind multilayer ridge priors offcat3 poisson300 37654 dots seed 20261031; unique; portal-safe (100 characters, ≤140 limit).
  6. Create the submission. The expected error “Predicted values must be in range [0, 1]” CANNOT occur for this file: it contains only 0.0/1.0, no NaN/Inf anywhere (zeros exterior), min 0.0, max 1.0. That error was produced by older NaN-outside research files; this one deliberately uses the portal-safe all-finite convention (see the writer docstring in src/gems/submission.py).
  7. After submitting: record the organizer-confirmed score on the submission page as ORGANIZER-CONFIRMED and compare with the MODEL-ESTIMATE 0.1393 (band -0.083–0.361) to calibrate the estimator. Cap: 3 submissions per week per the problem page — the remaining allowance shows on the submission page.

Budget/risk: the score is unverifiable before upload (no DrivenData auth from this sandbox). HOLDOUT-DTI 0.0944 [0.0814, 0.1073] is an internal diagnostic that does not forecast rank. Upload is always a manual owner action.
