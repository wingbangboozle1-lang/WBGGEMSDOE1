2 · Automatic gates (no human inspection step)

  1. Format: gems57.gates.format_report and gems57.validate.validate. Passes for the 31 Oct file.
  2. Exact copy: no positive set identical to any of the 482 local registry rasters.
  3. Lane rule: no more than 70% of the candidate's dots within 3 px of any one registry raster. Fails for the 31 Oct file (11 rasters, max 99.995% against the r13 lattice; 77.1% against GEMSDOE25 gem1 magnetics).
  4. Leakage canary: AUC above 0.90 means leakage. The 31 Oct file: closeness to the visible catalogue alone AUC 0.887 (passes, close to the limit).
  5. Holdout DTI: must beat the same-evaluator best. Not measured for the 31 Oct file (its eligibility used the full catalogue; a per-fold rebuild is needed first).

A file that fails any gate is research only. Gate receipts: evidence/session_20261031/candidate_overlap.json and candidate_run_card.json.

3 · Steps for a future submission

  1. Build the file with a pinned script, keeping the note and name within 140 characters.
  2. Run the automatic gates in section 2. Stop at the first failure.
  3. Pass the file to the separate selector step. Nothing is chosen automatically.
  4. Upload is a blocker for this sandbox: it needs a DrivenData login, which Arena cannot use here. The owner must upload from the portal.
  5. Any upload must carry the generative-AI disclosure required by the rules (29 Oct owner note).
