Why GEMSDOE32's B2 scored 0.2778 — and can we beat it?

  1. The metric rewards off-catalogue recall. Tversky/DTI (α=0.2, β=0.8, 300 m triangular kernel, problem page) penalises missed faults 4× more than false alarms. The hidden truth is the newly mapped fault network, so a dot on the public catalogue can never be a new-fault true positive — it only adds FP weight.
  2. The champion is a nested pruning sequence, not one idea. D2.8 (44,090 dots, keep distance ≥1 px from catalogue) → B1 (40,199, ≥2 px) → B2 (37,654, ≥3 px); reported 0.2600 → 0.2708 → 0.2778. Every removal is catalogue-adjacent mass that could only dilute precision.
  3. Geometry matters: Poisson-300 m kernel-disjoint dots (each dot buys independent kernel credit), 37,654 dots, coverage of ~92% of 6-km blocks (spreads FP risk map-wide), zero dots on the catalogue, only 5.8% of dots within 3 px of it.
  4. Caveats (verified): 0.2778 is USER-REPORTED, never organizer-confirmed here; scores in this family vary ±0.086 for near-identical rasters, so the top six of the nine sites are statistically tied; GEMSDOE25≡30 and GEMSDOE28↔31 are exact duplicate pairs.
  5. Beating it: keep the winning geometry, replace the placement surface. WBG-8 does exactly that with an independently implemented blind multi-layer geophysical ridge composite (magnetic RTP/TC Hessian ridges, geodetic strain magnitude, gravity edges, basement-depth steps, topo fronts) + visible-catalogue structural priors, fresh seed. Within-model geometry parity vs B2 is gap -0.014 (B2's own model estimate 0.1532); the model under-predicts the whole family, so read estimates relatively.
