### 3. Private-label inversion and causal explanations were overstated

For binary predictions, the shared metric gives

`DTI = T / [0.2 (T + N − M) + 0.8 K]`,

where `T = sum over truth cells of max prediction-kernel coverage`,
`M = sum over predicted dots of max truth-kernel coverage`, `N` is the predicted-dot
count, and `K` is the truth-cell count. **T and M are different quantities.**
A global lattice-average kernel value need not equal the average on the unknown fault
locations. Without those unknown geometry-dependent terms, the reported scalar metric
and lattice size do not establish a unique private-label count, private recall, or a
recall target for a new TIFF. Rounding and unverified historical score provenance add
further uncertainty. The LLI forecast was also trained on values claimed confirmed
without receipts and lacks untouched evidence of transfer to a new lane; it is not
published as an estimated leaderboard score.

The actual B2/parent nested pixel identity is useful and is retained in the nine-site
summary. It does **not** reveal whether all removed dots were false positives, the
location of hidden splays, or the exact causal reason for the reported score change.
Sparse coverage and avoiding low-marginal-credit emissions are plausible mechanisms,
not proven hidden-test facts. New tests would need clean fold-specific reconstructions,
not evaluating a static catalogue-pruned TIFF on faults it had already masked.

### 4. An export policy is not the organizer's private implementation

All four exact local TIFFs were reopened with the unchanged shared validator. They have
one float32 band, all-finite [0,1] values, the pinned reference CRS/shape/transform, zeros
outside the footprint and zero support on known faults. Reference integrity is checked
against the existing owner-mirror pins. This is local validation, not independent
organizer-origin authentication or a guarantee that the live portal accepts the file.
The originally rejected upload is not available to reconstruct its cause. All-finite
zeros-mode output is a conservative risk reduction; NaN, infinity, sentinels and
out-of-range values are rejected, not silently repaired.
