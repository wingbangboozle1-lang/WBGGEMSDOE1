OFFICIAL-PROBLEM

DrivenData GEMS problem description and submission format

retrieved, both chunks

  • The task is fault prediction for structures indicative of geothermal resources, not a direct geothermal-vent classification task.
  • New expert-mapped faults absent from the existing public USGS database form the initial test labels.
  • The metric uses max confidence times a 300 m triangular kernel; alpha=0.2 and beta=0.8.
  • Submission: one float32 GeoTIFF layer, values between 0 and 1, matching the projected EPSG:32611 100 m grid and bounds.
  • External data are allowed only with an appropriate license permitting use and sharing with the sponsor.
