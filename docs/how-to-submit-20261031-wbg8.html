How to submit the 31 Oct 2026 candidate

DOWNLOAD: YES · SUBMIT: OK. wbggemsdoe1-wbg8-hidden-corridor-34000-20261031-zeros is format-valid, unique and validated automatically by this project. Read the executive summary first; the run card is evidence/wbg8/run_card.json.

  1. Download the file. Use the one-click link on the executive summary: wbggemsdoe1-wbg8-hidden-corridor-34000-20261031-zeros.tif (or the single-GeoTIFF .zip). Verify SHA-256 cae1cc990da31a36373faebcb1d0cef729e50892cb59e30066d60da09d5f9448 if you want byte-level certainty.
  2. Open the submission form. DrivenData · New submission (requires your login; this project never stores or requests credentials).
  3. Choose the file. The form accepts a single-band GeoTIFF (.tif) or a .zip containing a single GeoTIFF. This file is a single-band float32 GeoTIFF on the exact submission grid (EPSG:32611, 3730 × 3292, the training geotransform) with every value in [0, 1] and zeros outside the footprint. Do not upload NaN-outside variants — NaN values are read as out of range and produce the error “Predicted values must be in range [0, 1]”.
  4. File name on the form: wbggemsdoe1-wbg8-hidden-corridor-34000-20261031-zeros.tif (unique; no earlier submission carries it).
  5. Note (optional but recommended): copy this note (95 characters, within the 140-character limit):
    WBG-8 lidar+basement+pf+rad corridors; 34,000 catalogue-neutral dots; MODEL-ESTIMATE ~0.26-0.29
  6. Submit. Keep the receipt page: the returned score is the only ORGANIZER-CONFIRMED number. Report it back to this project so the executive summary can be upgraded from MODEL-ESTIMATE to ORGANIZER-CONFIRMED.
  7. Weekly cap. The official rules (§3.2) limit submissions per week; the remaining allowance is visible only on your submissions page. This project has used no slot; promotion is deliberately left to you as the selector step.
