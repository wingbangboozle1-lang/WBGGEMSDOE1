## Pass 1 — audit and correction

The inherited WBG-2 approval contradicted this project's protocol. The recorded
registry comparison includes **100% forward overlap** with WBG-C1. The old gate
only stopped when overlap exceeded 70% **and** enrichment exceeded threefold.
The required rule is overlap >70% **or** rank correlation >0.90. No enrichment,
density, sparse-only or symmetric exemption is authorized. A saturated witness
need not indicate common geological reasoning; it still triggers the rule.

The original run card is preserved byte-for-byte in
`evidence/wbg2/run_card_before_protocol_correction.json`. The active card withdraws
approval and the forecast; exact TIFF/ZIP bytes are unchanged. The generator now
stops before placement, metric computation or private writer use. No new scientific
experiment, parameter search or registry-hole targeting was performed.

WBG-2 has **no qualifying HOLDOUT-DTI**: evaluator version, withheld-positive count
and 95% CI are unavailable. Comparing to the full catalogue while explicitly
excluding it is not hide-and-recover. Catalogue-derived KDE must be reconstructed
from visible segments independently in each buffered fold. Neither individual
feature canaries nor a same-evaluator current-best victory is supplied for WBG-2.

The old nine-point regression is not a validated leaderboard forecasting model:
related/pruned outputs, one identical prediction pair, collinear predictors,
out-of-support application, and no untouched lane-transfer test invalidate strong
transfer claims. A residual-SD interval ignores parameter and new-case uncertainty.
The previous 0.2824 forecast and its narrow interval are withdrawn, not relabeled
as a score. Fitting historical scores cannot replace spatial holdout validation.
