How to submit (read first)

Status now: no file is cleared for portal submission. The research TIFs are format-valid; the lane-gate decision is open (see the executive summary).

1. What the portal requires (official rules)

  • Single-band float32 GeoTIFF, EPSG:32611, 100 m grid. Shape 3730 x 3292. Transform (100, 0, 243350, 0, -100, 4508550), matching data/bridge/sample_submission.tif.
  • Predicted values in [0, 1]; no inf; no NaN inside the footprint. Outside the footprint the rules allow null or NaN.
  • Source: Official Rules.

2. The "Predicted values must be in range [0, 1]" error - status

Root cause: not verified. Verified facts only:

  • Every research TIF here passes the format checks, with zeros outside the footprint.
  • Both zeros-outside and NaN-outside files have USER-REPORTED scores, so the outside convention alone is not the proven cause.
  • GEMSDOE31 csdu-stepover-nan has 2,610,312 NaN cells inside the footprint. That breaks an explicit rule, but this is not proven to cause the portal error.
  • 14GEMSDOE horse-ensemble has a transform that differs from the reference grid.

3. Steps

  1. Write the raster as float32, zeros outside the footprint, values in [0, 1].
  2. Validate: python scripts/validate_candidate_tif.py FILE.tif. It prints JSON and exits 0 only if every check passes.
  3. Name the file uniquely: <method>-<arm>-<date>-<k-dots>-zeros.tif. Example: wbggemsdoe1-novel-band3to8-s5-e1-k33884-20261029-zeros.tif.
  4. Write a submission note of 140 characters or fewer. Example (98 characters): "Novelty band 3-8 px off catalogue, 33884 dots, zeros outside; no score claimed; gates in run card."
  5. Submit only if the run card says ok_to_submit: true. Never submit a file marked NOT-SUBMITTED.

4. Gates before any submission

  • Format and range: all checks pass.
  • Lane gate: overlap within 3 px at most 0.70 and |rho| at most 0.90 against distinct registry rasters. Currently FAILS for all candidates.
  • Holdout DTI is a sanity check only, never a gate or a score.
