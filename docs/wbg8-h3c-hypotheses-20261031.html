Why these five, and what was rejected

The candidate list was screened against the measured 118-file portfolio, not against taste: a hypothesis whose mechanism is already represented in a scored sibling file has to clear that file's number, not a holdout. Radiometric/alteration and geodetic-strain primaries were demoted for exactly that reason (0.0782, 0.0558, 0.0963, 0.0000, 0.0132 owner-reported).

Non-fault mimics that must be argued against

  • lithologic contacts offsetting both potential fields (the strongest confounder of H1);
  • alluvial-channel and pediment boundaries, which create relief deficits with no structure;
  • DEM/magnetic interpolation artifacts shared between derived bands;
  • mining or seismicity-grid sampling footprints, which imprint on the geodetic and earthquake bands.
