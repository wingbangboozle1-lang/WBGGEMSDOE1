2. What can and cannot be inferred about GEMSDOE32 B2's reported 0.2778

The official problem description defines a distance-weighted Tversky score (α=0.2, β=0.8) with a 300 m triangular kernel and hidden fault labels; see the official problem page. The value 0.2778 for GEMSDOE32 B2 and the comparison values in the table are OWNER-REPORTED, not tied to an organizer receipt in this repository.

Local raster forensics record B2 as a subset of the D2.8 parent with 6,436 fewer dots, none added, and the removed dots near the mapped catalogue. This establishes a pixel-level relationship, not why the reported score changed. Fewer redundant or catalogue-adjacent predictions could reduce false-positive penalty while retaining some kernel coverage; hidden labels are unavailable here, so this remains a plausible mechanism, not a causal result.

The archived score-inversion exercise reproduces one reported lattice value under an assumed random truth model. Its inferred K≈12,395 and null/“uplift” figures are MODEL OUTPUTS conditional on the assumed truth distribution and an unverified score; they do not measure the hidden truth size or B2's localization skill. Separately, the recovered submission archive contains correlated variants; its leave-one-family validation and the hide-and-recover comparison do not validate a leaderboard ranker. No score projection for a new raster is justified by those analyses.

Can a unique file beat 0.2778? That is unknown. The reported 0.2778 itself is not organizer-confirmed, and this repository has no validated prospective estimate or eligible candidate. A defensible claim would require authentic labels/inputs or a protocol-valid, leakage-controlled holdout that beats a same-evaluator comparator, plus exact final-file validation and the separate selector step.

3. WBG-6 artifact properties and limits

  • Its generator used an archived catalogue-distance profile and kernel-spacing rule. These describe the construction, not independent geological evidence for hidden faults.
  • The archived raster has 30,000 positive cells and reports zero on the mapped catalogue. Local format validity does not establish uniqueness, scientific value, portal acceptance, or an organizer score.
  • The explicit active registry rule is literal: stop if over 70% of candidate dots lie within 3 px of any registry raster. Its recorded maximum is 99.6767%, so WBG-6 fails. A density-adjusted statistic is not authorized to waive this threshold.
  • There is no current leaderboard estimate supported by a validated model. The archived MODEL-ESTIMATE is retained only for provenance and must not be used to choose a slot.

4. Registry comparison — literal rule governs

The archived audit compared 118 historical rasters. Byte novelty and surface correlation are not enough to clear the independent proximity stop:

  • byte-identical among that archived scope: no;
  • maximum archived surface |Spearman ρ|: 0.0148;
  • maximum forward 3-px overlap: 99.6767% against 20261001_r13-lattice-s5_v2_nan-outside (active limit 70%);
  • density-adjusted overlap lift was also recorded, but it does not replace or waive the literal rule.

Decision: duplicate STOP under the stated protocol. Do not tune around registry coverage or reinterpret this historical comparison. Its scope is frozen and incomplete; a fresh complete registry audit would still be required for any future candidate.

6. Limitations and irregularities (nothing here is hidden)

New this pass — the shared holdout was re-tested two ways. We re-scored all 118 recovered rasters against the segment holdout under (a) the repo's rule, which forgives dots placed on the mapped catalogue, and (b) the organiser's rule, which counts them as false positives. The two variants return identical numbers: these rasters were all built to avoid the catalogue, so the forgiveness rule is inert and is not why the proxy fails. Corrected or not, the proxy still does not rank real scores (ρ = +0.125, p = 0.18). The reason is structural: the withheld components were visible to the authors when the rasters were made, so the proxy scores catalogue-following, not detection of unmapped faults.

  • No organizer confirmation. Every historical score in this repo is the owner's own report; no submission-page receipt identifies those bytes. The leaderboard figure is a public page observation, not a score for any project file.
  • Only 22 independent observations. 118 files reduce to 22 near-duplicate families, so any fitted relationship has a very small effective sample. Both the descriptor model and the holdout proxy fail grouped validation, and this page says so rather than quoting the flattering in-sample number.
  • The MODEL-ESTIMATE is not validated. Its uplift comes from historical score reports, not an independent experiment on this file; the held-out proxy did not validate ranking. Do not interpret its interval as a confidence interval for leaderboard performance.
  • No feature stack, no 1 m DEM. Both are egress-blocked here; without them a supervised prior cannot be trained, which caps achievable precision (see §2).
  • Note text. The competition allows a ≤140-character note; use WBG-6 quantile-matched habitat, kernel-disjoint 30k dots, off-catalogue so the entry is identifiable later.
