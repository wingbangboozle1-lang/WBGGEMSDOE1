Hypothesis 1: Blind-zone ring emission — IMPLEMENTED

This is the hypothesis behind the new unique TIF submission.

Layers involved

  • Public catalogue fault raster (data/bridge/labels.tif), 60,988 catalogue fault pixels

Physical signature

Distance-from-mapped-fault Gaussian ring peaked at ~220 m from the nearest catalogue fault. Targets blind geothermal faults that are structurally related to mapped faults (stepovers, splays, parallel strands) but not on them — the "blind zone" between mapped structures where undiscovered faults hide.

Why it catches catalogue-missing faults

Catalogue faults are the mapped, known structures. Blind faults in geothermal systems commonly terminate at, splay from, or run parallel to mapped faults at a measurable offset. A ring emission at 150–300 m captures this offset zone without the false-positive cost of placing dots on known faults (which are masked from FP in the metric but add no discovery value).

How it differs from the repo

Existing lanes (GEMSDOE25/30/31/32) use hard catalogue-distance cutoffs on a single dense base field (D2.8: dots on/near catalogue; B1: >100 m exclusion; B2: >200 m exclusion). WBG-C1 uses ML on the 19-band stack with a Hessian commutator. This lane uses a continuous Gaussian-ring emission surface with priority Poisson dot placement — no ML, no hidden labels, no sample pixels as features, no hard cutoff.

Validation result

New TIF: WBGGEMSDOE1-blind-zone-ring-220-0m-120-0m-20261028-d63a12ef423e-zero.tif. 30,000 dots, min 4 px spacing, Gaussian ring peak 220 m / sigma 120 m / width 90 m. HOLDAUD-DTI local proxy: 0.2245. Format: all 11 hard checks pass. Unique: no byte copy among existing project TIFFs; 0% of dots within 3 px of WBG-6 dots.

Named non-fault mimic

Lithologic contacts, erosion scarps and survey gridding seams can also produce distance-from-fault rings. This is a structural hypothesis, not a verified geothermal discovery.

Hypothesis 2: Magnetic trough + radiometric potassium co-location

Not yet implemented — blocked by data access (needs the login-gated 19-band stack or GeoDAWN original bands).

Layers involved

  • USGS GeoDAWN airborne magnetic survey: RTP (reduced-to-pole) and TMI (total magnetic intensity)
  • USGS GeoDAWN radiometrics: potassium (K), thorium, uranium channels

Physical signature

Hydrothermal alteration demagnetizes host rock (magnetic trough) and introduces potassium enrichment (adularia, illite). Co-located magnetic low + K high, away from catalogue faults, indicates a blind hydrothermal system.

Why it catches catalogue-missing faults

Many blind geothermal systems in the Great Basin have no surface fault expression but show hydrothermal alteration halos. The magnetic-radiometric co-location detects the alteration, not the fault trace itself, catching systems the catalogue misses entirely.

How it differs from the repo

The repo's WBG-5 MTA-1 lane tests magnetic texture alone (AUC canary passed, but null DTI result). No lane combines magnetic trough with radiometric K. The 19-band stack (login-gated) contains mag_anom, rtp, tmi bands but radiometric K/U/Th bands are not confirmed in the local mirror.

Data needed

Free official USGS GeoDAWN radiometric survey (DOI 10.5066/P93LGLVQ) — check obtainability before implementing. Without radiometric bands, this hypothesis cannot be tested locally.

Named non-fault mimic

Lithologic contacts (felsic intrusions are naturally K-rich and weakly magnetic), survey leveling artifacts, and topographic correction residuals can mimic co-located magnetic low + K high.

Leakage canary

Test each band alone (RTP alone, K alone) before combining. AUC > 0.90 for either band alone would indicate leakage (band correlates too perfectly with catalogue faults).

Hypothesis 3: Fault-intersection & stepover density

Not yet implemented — can be done with catalogue raster only (CPU, low cost).

Layers involved

  • Catalogue fault raster, vectorised to fault line segments

Physical signature

High local density of fault intersections, stepovers, and relay ramps within a 1 km structural window. These are dilational jogs where geothermal fluids ascend.

Why it catches catalogue-missing faults

Blind faults often nucleate at or near fault intersections where stress concentrations are highest. Intersections of mapped faults are known points, but the *density field* around them highlights off-catalogue secondary splays that aren't individually mapped.

How it differs from the repo

No existing lane computes intersection/stepover density from the catalogue. GEMSDOE33's analog-tip/stepover file uses stepovers but as a post-hoc filter on existing dots, not as a primary emission surface.

Named non-fault mimic

Map artifacts where fault lines cross due to digitization errors, and areas of complex lithology where multiple mapped contacts converge without structural meaning.

Implementation cost

Low: vectorise catalogue raster (gdal polygonize), compute intersection kernel density, output emission surface. No external data needed.

Hypothesis 4: Curvature-slope convergence (topographic wetness analog)

Not yet implemented — needs LiDAR DEM derivatives.

Layers involved

  • 1 m LiDAR DEM derivatives: plan curvature, profile curvature, slope

Physical signature

Convergent (negative) plan curvature combined with low slope along linear trends — spring-line and sinter-terrace morphology typical of fault-controlled geothermal discharge.

Why it catches catalogue-missing faults

Blind faults with surface water discharge create subtle topographic expression (micro-scarps, linear depressions) not mapped in the catalogue. Curvature-slope convergence isolates these subtle features.

How it differs from the repo

The WBG-S2 (MKSF-1) lane uses 10 m DEM + 1 m LiDAR Vierbein-Coulomb but is stopped on overlap gates. No lane uses curvature-slope convergence as a primary emission surface. The local LiDAR scarp features JSON exists but the full DEM derivatives are not locally available.

Data needed

1 m LiDAR DEM derivatives (USGS 3DEP or the INGENIOUS project LiDAR). Check obtainability.

Named non-fault mimic

Erosion gullies, alluvial fan toes, and road/rail cut/fill embankments produce convergent curvature + low slope without fault control.

Hypothesis 5: Directional distance-to-catalogue (along-strike vs across-strike)

Not yet implemented — can be done with catalogue raster only (CPU, low cost).

Layers involved

  • Catalogue fault raster
  • Local strike orientation (from catalogue fault gradient structure tensor)

Physical signature

Blind faults tend to run parallel to mapped strands at a consistent offset (en echelon arrays). An anisotropic distance transform — wider kernel across strike, narrower along strike — captures this directional relationship.

Why it catches catalogue-missing faults

Geothermal fault systems in extensional terrain commonly form en echelon arrays. Off-catalogue segments parallel to mapped faults at 200–800 m offset are missed by isotropic distance thresholds (B1/B2 use the same cutoff in all directions).

How it differs from the repo

Existing lanes use isotropic distance cutoffs (same threshold in all directions). No lane uses a directionally anisotropic kernel derived from local fault strike.

Named non-fault mimic

Sedimentary bedding contacts and volcanic flow boundaries can be parallel to mapped faults without being faults.

Implementation cost

Low: compute local strike from catalogue gradient, build anisotropic distance kernel, emit surface. No external data needed.
