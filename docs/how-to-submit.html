1. File

Upload a single-band GeoTIFF or a .zip containing one GeoTIFF.

  • CRS EPSG:32611 (UTM 11N), 100 m, shape 3730×3292, geotransform identical to example_submission.tif / sample_submission.tif.
  • dtype float32, values in [0, 1].
  • Use the -zeros.tif encoding (0.0 outside the footprint, nodata=None, zero NaNs anywhere). A previous upload of a NaN-outside raster returned Predicted values must be in range [0, 1]. The official text allows NaN outside the bounds; the portal validator in practice rejects non-finite values. This repo always ships the zeros twin as the upload file.

Official format: page 967, submission format.

2. Portal

  1. Log in at DrivenData.
  2. Open New submission for competition 306.
  3. Choose the zeros GeoTIFF or its zip.
  4. Note field (optional, ≤140 characters). Copy the run-card submission_note exactly.
  5. Submit. Record the receipt (score, hash, timestamp) back into evidence/ — we do not have organizer receipts today.

4. Automated gates this repo runs before any “OK TO SUBMIT”

  1. SHA-256 pins of the three official rasters.
  2. Leakage canary: every detector feature AUC ≤ 0.90 on hide-and-recover (distance-to-full-catalogue is the positive control and must exceed 0.90).
  3. Hide-and-recover pooled DTI (α=0.2, β=0.8, 300 m kernel, whole-segment withhold, visible-only B-collar) beats the champion proxy with the same evaluator.
  4. Surface Spearman ≤ 0.90 and final-dot 3 px overlap ≤ 70% vs every non-space-filling registry raster.
  5. Strict validator: CRS/shape/transform, float32, all cells finite in [0, 1], 0 catalogue dots.
