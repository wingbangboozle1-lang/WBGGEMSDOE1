How a human would submit — if the banner said GO

It does not. The steps are documented on How to submit so that when a future experiment beats holdout, the upload path is mechanical:

  1. Use the zeros-mode GeoTIFF (never the NaN twin) so the portal cannot raise “Predicted values must be in range [0, 1]”.
  2. Open New submission.
  3. Attach the .tif or the single-TIFF .zip.
  4. Paste the unique name into your records and the ≤140-character note into the Note field.
  5. Do this only when the homepage banner is green and the run card verdict is promote.

Scientific answer to the 0.2778 question

0.2778 is not a mysterious model. It is D2.8 (44,090 Poisson-thinned H19-5 ridge dots, live 0.2600) minus every dot within 2 px of the published catalogue, leaving 37,654 dots. That collar is a dead annulus for the test set. Unique files are forced off that network and, under every live-calibrated analysis published by GEMSDOE32 and confirmed by our 3 px overlap numbers, pay false-positive mass where there is little hidden truth. Beating 0.2778 without duplicating H19-5 requires either (a) a detector with ≥7× lift in the off-network strata, which E2/E3 did not provide, or (b) a rule change allowing H19-5 family refinements.
