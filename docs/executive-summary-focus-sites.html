02 / Why did GEMSDOE32 score 0.2778, and can it be beaten?

Forensics of the top supplied file

What the bytes establish

The GEMSDOE32 file is exactly the inherited D2.8 field (44,090 dots) pruned by catalogue distance:

  • D2.8: 44,090 dots (shared with GEMSDOE30 — byte-different encodings, identical predictions).
  • GEMSDOE31 base (B1): remove 3,891 dots within 100 m of the public catalogue → 40,199 dots.
  • GEMSDOE32 B2: remove another 2,545 dots within 200 m of the catalogue → 37,654 dots.

These are exact set identities measured from the recovered files, not inferences from filenames. GEMSDOE36 keeps all of B2 and adds 1,200 dots (38,854), yet its supplied value (0.2750) is below B2's (0.2778).

Plausible mechanism (not proven)

The official metric is a distance-weighted Tversky index: each truth cell earns credit from the strongest nearby prediction, and redundant predictions add false-positive cost with little new credit. Sparse placement + pruning low-marginal-credit, catalogue-near dots can raise DTI. That makes 0.2778 plausible as a precision play — but hidden labels are unavailable, so this is a plausible mechanism, not a proved cause, and a 200 m exclusion is not an organizer rule.

Can it be beaten?

We cannot verify this. There is no DrivenData authentication in this environment, no hidden-label access, and no organizer receipt for any project file. The public leaderboard is higher than 0.2778, but that is not a score for any project TIFF. A unique file could beat 0.2778 in principle, but nothing in this repo establishes it. WBG-7 below is a genuine, unique, format-valid entry; treat its leaderboard score as unknown.

04 / Candidate geological hypotheses (not yet tried in this repo)

Ranked by expected DTI improvement vs implementation cost

#Hypothesis & layersPhysical signature targetedWhy it catches a missing (off-catalogue) faultExpected benefit / cost
H1 Blind trace-tip splay (implemented → WBG-7). Catalogue trace tips (skeleton endpoints of labels.tif) projected outward off-trace as directional lobes, weighted by 200–800 m distance rings. Directional splay lobe from trace ends into the off-catalogue side; distance-to-catalogue ring (2–8 px peak). Blind geothermal faults nucleate as short splays at the ends of mapped traces (Faulds et al. 2019; Siler 2023). Dots stay off catalogue (no guaranteed false positives) but inside the 300 m DTI kernel for partial credit. Highest benefit / low cost — uses only the local catalogue.
H2 Off-catalogue distance rings (GEMSDOE32-B2 lineage, re-derived independently as the WBG-7 blend control). Pure distance-from-catalogue propensity, no structural targeting. Triangular distance-to-catalogue weight peaking at 200–600 m. The competition truth is faults absent from the catalogue; dots off-catalogue avoid guaranteed false positives. This is the proven sparse-pruning family that produced the 0.2778 claim. Medium benefit / low cost — the control WBG-7 is blended against.
H3 Inter-trace relay-zone propensity. Pairs of nearby, similarly-oriented catalogue traces separated by 3–12 px; target the gap midline off-catalogue where blind transfer faults form. Gap-midline mask between parallel traces, weighted by gap width and strike alignment. Stepovers and relay ramps are classic sites for blind, unmapped displacement between mapped range-front faults. Medium benefit / medium cost — needs pair detection; not yet implemented.
H4 Trace-network outer-envelope gradient. Morphological gradient (dilation − erosion) of the dilated catalogue network, restricted to off-catalogue cells where new faults branch off the main network. Morphological edge / outer envelope of the catalogue fault network. New splays nucleate at the outer edge of an existing fault network; targets branch points not already mapped. Uncertain benefit / low cost — morphology only; not yet implemented.
H5 Trace-centerline curvature (kinks / restraining-releasing bends). High-curvature points on skeletonized traces, dilated off-catalogue into the stepover side. Centerline curvature magnitude, dilated off the catalogue. Bends and kinks localize strain and are where blind splays step off the mapped trace. Uncertain benefit / low cost — skeleton curvature; not yet implemented.

H1 is implemented in WBG-7 and validated (canary pass, uniqueness pass, format pass). H2 is the blended control. H3–H5 are documented, untested candidates requiring a future session: none need new external data, all use the local catalogue + grid. The named non-fault mimics for H1 are trace terminations without displacement continuation, lithologic contacts ending at the trace, and mapping edge artifacts.

05 / How to make a submission into the contest

Step-by-step submission guide

  1. Pick an approved file. Only upload a single-band GeoTIFF (.tif), or a .zip containing exactly one GeoTIFF. The file must match the submission format's CRS (EPSG:32611), shape (3730×3292), 100 m geotransform and have every value in [0,1]. WBG-7 above meets these local checks.
  2. Verify locally before upload. Reopen the exact TIFF bytes, confirm no NaN/inf inside the footprint, values in [0,1] over the whole array, CRS/shape/transform match the reference grid, and that a ZIP contains exactly one identical TIFF. Do not open/resave the TIFF in software that changes pixels or metadata.
  3. Use the contest's "New submission" form. Go to the DrivenData submissions page (login required), choose the .tif or its one-TIFF .zip, paste a short note (≤140 characters, e.g. the WBG-7 note above), respect your remaining weekly allowance, and submit.
  4. Retain the organizer receipt. Record the submission identifier, exact artifact SHA-256, time, note and the result copied from the submission page. Only then label a result ORGANIZER-CONFIRMED. The public leaderboard alone does not identify your file.
