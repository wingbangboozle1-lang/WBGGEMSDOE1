Why GEMSDOE32's 0.2778 led the supplied group

GEMSDOE32 B2 is an exact 37,654-dot subset of the GEMSDOE25/GEMSDOE30 D2.8 field: 6,436 dots at catalogue distance <= 200 m were removed, zero added. GEMSDOE36 is a 1,200-dot superset of B2.

Distance-weighted Tversky gives each truth pixel the maximum nearby prediction credit. Redundant near-catalogue dots add false-positive mass with little new coverage, so sparse pruning can improve DTI. This is a metric/geometry explanation, not proof about hidden labels.

Can we beat it? Not in this session. No newly generated or inherited unique file cleared the frozen promotion gates; an organizer receipt for 0.2778 was never supplied.
