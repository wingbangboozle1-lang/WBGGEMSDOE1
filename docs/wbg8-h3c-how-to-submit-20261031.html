2. Portal steps (no local step substitutes for them)

  1. Open the submissions page of competition 306 and log in.
  2. Click New submission → File to submit and pick the .tif (or the .zip containing exactly that one GeoTIFF).
  3. Set the name/note field to H3c: 42,771 kernel-disjoint dots, 11 px lattice, each on its local consensus maximum. MODEL-ESTIMATE 0.23-0.35. Break-even hit rate 12 pct. (the portal allows a short comment; it must not be empty if you want the receipt to be attributable).
  4. Press Create submission. The portal scores it against the public test chunk and writes a row into your submission history; that row is the only ORGANIZER-CONFIRMED number that will ever exist for this file.
  5. Record the score back into this repository (add it to registry/registry.json with the file's SHA-256) so the estimator can be calibrated on a real receipt instead of an owner-reported value.

Weekly limits and the one-selected-submission rule are enforced by the portal, not by this project; this repository has no uploader and never spends a slot.
