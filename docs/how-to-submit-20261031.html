2 · The range error, and what fixes it

The organizer’s check requires every predicted value to lie in [0, 1], with no NaN, Inf or sentinel values inside the study area. The error means the file held a value outside that range, or NaN or Inf inside the footprint. The repo does not record which earlier upload triggered it, so this page does not name a cause.

The fix is to write the file as follows. The validator above checks each point automatically:

  • One band, float32, EPSG:32611, 100 m cells, 3730×3292, the sample transform.
  • Inside the sample footprint: every value is finite and in [0, 1]. This file uses only 0.0 and 1.0.
  • Outside the footprint: 0 or NaN, matching the official sample.
  • No Inf and no sentinel values anywhere.
