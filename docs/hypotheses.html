H1 — Blind-fault adjacency with distance-decayed emission (IMPLEMENTED)
Layers, signature, rationale, mimic, distinction

Layers: existing_faults.tif (USGS/INGENIOUS catalogue) + competition grid.

Physical signature: blind faults occur adjacent to — not on — mapped traces (splays, stepovers, blind extensions). Smooth Gaussian distance kernel peaking ~150 m from catalogue, decaying toward both the catalogue (already mapped) and far background.

Off-catalogue rationale: targets faults near but not on mapped traces — precisely the faults the catalogue misses. GEMSDOE32 B2 used a hard >200 m cut; this uses a smooth peak at ~150 m, giving higher weight to the blind-fault adjacency zone and less to distant background.

Named non-fault mimic: linear topography / DEM scarp edges unrelated to faults can produce similar distance-from-catalogue structure.

Distinction from existing repo work: no existing lane uses a smooth distance-decay emission. All historical lanes use hard thresholds (GEMSDOE32 B2's >200 m), unvalidated ML proxies, or ridge-thinning families. This is a distinct construction.

Implementation: scripts/generate_unique_submission.py → docs/downloads/WBGGEMSDOE1-blind-fault-adjacency-distance-decay-20261028T202056Z.tif

Measured: HOLDOUT-DTI 0.4657, 95% CI [0.4563, 0.4748], evaluator WBGGEMSDOE1-HIDE-RECOVER-v1.0, 60,161 withheld positives, 129,184 dots, zero dots on catalogue.

Leakage caveat: dot placement used the full catalogue, not per-fold visible faults as the protocol requires. HOLDOUT-DTI may be inflated. Per-fold re-evaluation required before slot promotion.

H2 — Curvature/dilatation boundary persistence at 300–800 m (UNTESTED)
Layers, signature, rationale, mimic, distinction

Layers: cached cond_surf (band 17), depth_to_base_surf (band 15), geod_dilaterate (band 8).

Physical signature: multiscale non-coaxial curvature — the normalized Hessian commutator detects disagreement in principal curvature directions — combined with persistent dilatation boundaries. This marks concealed structural complexity without catalogue proximity.

Off-catalogue rationale: a fault can be blind even where no mapped trace exists nearby. Curvature/dilatation disagreement flags concealed geometry independent of catalogue distance.

Named non-fault mimic: oblique saline-clay basin fill, lithologic contacts, shared inversion artifacts can produce the same signature.

Distinction: tested once as WBG-C1 (negative), but never combined with distance-decay emission. The operator itself is not found in inspected shared code, but global/unpublished novelty is not established.

Expected DTI improvement: qualitative and uncertain — never a numeric forecast.

Cost: low — uses existing 19-band cache; no external data.

Official references: Siler (2023), USGS · Faulds et al. (2019), USGS.

H3 — Depth-conditioned magnetic texture transport (UNTESTED)
Layers, signature, rationale, mimic, distinction

Layers: cached RTP, TMI and depth proxy bands.

Physical signature: lagged texture changes along vs across depth-contour directions — may flag covered offsets without an exposed scarp.

Off-catalogue rationale: targets buried structures invisible to surface fault mapping.

Named non-fault mimic: volcanic/intrusive contacts, survey leveling artifacts.

Distinction: more specific than a scalar magnetic amplitude edge; related texture/phase proposals exist in peer code, so exact added information and lane novelty are unknown.

Expected DTI improvement: untested.

Cost: medium — uses existing cache; no external data needed for initial screen.

H4 — Radiometric compositional changes across terrain saddles (CONDITIONAL)
Layers, signature, rationale, mimic, distinction

Layers: USGS GeoDAWN K/Th/U radiometrics + terrain saddles derived from DEM.

Physical signature: tangent-coherent cross-saddle compositional changes — not raw counts — suggesting fracture-controlled alteration outside mapped traces.

Off-catalogue rationale: hydrothermal alteration can be blind to fault mapping; saddle-focused compositional changes target blind convection pathways.

Named non-fault mimic: sediment sorting, weathering, lithology.

Distinction: ratio features exist in peer code — a ratio alone is not novel. Needs a physically motivated tangent-coherent statistic.

Expected DTI improvement: untested.

Cost: medium — conditional on original-layer semantics and coverage verification.

Official free source: USGS GeoDAWN airborne magnetic and radiometric surveys (DOI 10.5066/P93LGLVQ) — obtainable before proposing as viable.

H5 — Anisotropic conductivity-boundary persistence (UNTESTED)
Layers, signature, rationale, mimic, distinction

Layers: cached conductivity and depth proxies.

Physical signature: boundary survival under smoothing along but not across a local orientation tensor — retains elongated concealed discontinuities that scalar edge detection loses.

Off-catalogue rationale: targets extended blind structures that surface fault mapping misses.

Named non-fault mimic: saline deposits, gridding seams.

Distinction: different statistic from a scalar edge; related coherence/vesselness operators already exist, so added value is uncertain.

Expected DTI improvement: untested.

Cost: medium — needs a future assigned lane and frozen validation; not an automatic slot.

How to evaluate before spending a slot
  1. Implement the hypothesis using only the shared cached feature stack (19 bands).
  2. Run hide-and-recover holdout: withhold whole fault segments with buffer, derive catalogue features from visible faults only, mask visible faults pixel-exactly, score pooled DTI (α=0.2, β=0.8, 300 m triangular kernel).
  3. Run leakage canary: test each feature alone. AUC > 0.90 means leakage until proven otherwise.
  4. Check surface novelty: |Spearman| ≤ 0.90 vs every registry raster; final-dot 3-px overlap ≤ 70%.
  5. If holdout DTI beats the current same-evaluator best with a strictly positive 95% CI, bring to a separate selector for slot consideration.

Budget: stop after 3 experiments or 2 hours. Negative results are deliverables.
