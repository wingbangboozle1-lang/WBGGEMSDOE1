Two pruning steps, each measured on the live ladder (OWNER-REPORT, nested set inclusion verified across the nine files this session): H19-5 0.1922 → D1.5 0.2477 (G24) → D2.8 0.2600 (G25 = G30, 44,090 dots) → B1 0.2708 (G31, 40,199) → B2 0.2778 (G32, 37,654). Near-catalogue dots are almost pure false positives because the test set contains only new faults.

The uniqueness rule requires ≥30% of dots more than 3 px from that network. Those off-network strata have been repeatedly measured as near the break-even floor.
