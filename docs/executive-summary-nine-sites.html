Why GEMSDOE32 leads the supplied group

Measured raster identities from the inspected files.

Set relationships (verified from bytes)

  • D2.8: 44,090 dots — shared base field (GEMSDOE25 = GEMSDOE30)
  • B1: 40,199 dots — D2.8 minus 3,891 dots within 100 m of catalogue (GEMSDOE31)
  • B2: 37,654 dots — B1 minus 2,545 more dots within 200 m of catalogue (GEMSDOE32)
  • GEMSDOE36: 38,854 dots — all of B2 plus 1,200 additions

Mechanism (plausible, not proven): the official metric is a distance-weighted Tversky index. Redundant dots add false-positive mass with little new true-positive credit. Pruning low-marginal-credit dots (far from catalogue) raises DTI. B2's 200 m exclusion improved the reported value over B1. A 200 m exclusion is not an organizer rule.

Can it be beaten?

  • In principle yes. The public leaderboard shows values above 0.2778, but no project TIFF receipt is tied to those observations.
  • No experiment here establishes a higher project result. Hidden labels are unavailable; the historical values are user-reported, not organizer-confirmed.
  • Copying GEMSDOE32 B2 violates the unique-submission requirement. A new file must differ in pixels, not just filename.

05 /

Scientific hypothesis behind the new submission

Blind-zone ring emission: geothermal faults cluster near but not on mapped catalogue faults (stepovers, splays, parallel strands).

Layers used

Public catalogue fault raster only (data/bridge/labels.tif). No 19-band stack, no ML, no sample-submission pixels as features.

Physical signature

Distance-from-mapped-fault ring peaked at ~220 m — the blind zone between mapped structures where undiscovered faults may hide.

Named non-fault mimic

Lithologic contacts, erosion scarps and survey gridding seams can also produce distance-from-fault rings. This is a structural hypothesis, not a verified geothermal discovery.

How it differs

Existing lanes use hard catalogue-distance cutoffs on one dense base field (D2.8/B1/B2) or ML on the 19-band stack. This lane uses a continuous Gaussian-ring emission surface with priority Poisson dot placement — no ML, no hidden labels, no sample pixels as features.

Local holdout result (proxy)

HOLDAUD-DTI 0.2245 on the public-catalogue hide-and-recover protocol (α=0.2, β=0.8, 300 m triangular kernel). This is a local proxy against the mapped catalogue, not an organizer score and not a leaderboard forecast.

Validation

All 11 hard format checks pass. No NaN/inf inside the footprint, values in [0,1], CRS/shape/transform match the template, zero dots on mapped catalogue faults. Run card and validator JSON are saved next to the TIFF.
