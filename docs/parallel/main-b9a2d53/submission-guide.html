Required gates before any download is approved

  1. Use the competition's actual training-feature grid/sample submission as the reference, not a guessed grid.
  2. Run buffered whole-segment spatial holdout using the shared project evaluator. Report only measured HOLDOUT-DTI results with evaluator version, withheld-positive count and 95% CI. A model projection is not a score.
  3. Check the standalone feature leakage canary; any AUC above 0.90 requires investigating leakage before use.
  4. Compare the proposed raster to every available registry raster before placement and after final dot selection. If rank correlation exceeds 0.90 or over 70% of dots are within 3 px of one registry's dots, classify as duplicate and stop.
  5. Validate the final GeoTIFF locally with python scripts/validate_submission.py candidate.tif data/sample_submission.tif. A green result only validates raster structure/range/footprint; it does not certify score, scientific validity, originality, or organizer acceptance.
  6. Have the separate selector compare holdout performance with the existing holdout best and verify the competition's current weekly cap. A weekly slot is not used by validation itself.

Expected raster format (official competition specification)

PropertyRequired value
FileOne single-band GeoTIFF (.tif), or a ZIP containing exactly one GeoTIFF
CRSEPSG:32611 (UTM zone 11N)

BandExactly one, float32
PredictionsFinite probabilities/confidence values in [0, 1] throughout the data footprint
Outside footprintNull/nodata or NaN; no finite predictions outside

These format requirements are transcribed from the official problem page. DrivenData remains the authority for current rules and upload form validation.

Upload after approval

  1. Open the GEMS competition page and sign in to the authorized account.
  2. Open the competition's submission form and choose the approved .tif (or ZIP containing a single GeoTIFF).
  3. Enter a unique descriptive submission name and a short comment of no more than 140 characters. Name should encode the hypothesis/version; comment should briefly explain the distinguishing method.
  4. Submit only after the form accepts the file. Save the submission-page receipt; this receipt is the source for any value labelled ORGANIZER-CONFIRMED.

Do not submit automatically from this project. The project's role is to give you a locally validated, clearly identified artifact only after the research/selector gates pass.

Validator command and interpretation

Install the geospatial requirements in requirements.txt, then run:

python -m pip install -r requirements.txt
python scripts/validate_submission.py path/to/candidate.tif path/to/sample_submission.tif

JSON output includes ok, errors, CRS/shape/transform, band count and type, range/finiteness checks, footprint checks, and candidate SHA-256. Nonzero exit means do not submit. The checker does not create a TIF or alter the input.
