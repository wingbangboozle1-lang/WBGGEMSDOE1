1. Download the exact file

2. Verify the checksum

# expect 80a87d9f6c741d3aefb558e7fc4794c2ddf058d5cb1b62b3aed4266fe984c81e

3. Re-run the local validator

.venv/bin/python scripts/validate_submission.py \
  docs/downloads/wbggemsdoe1-wbg5-dcoc-blend75-submod-20261028T170845Z-zeros.tif
# expect format PASS

4. Confirm account allowance

The official rules (section 3.4) allow up to three entries per week. The logged-in submission page shows the actual remaining allowance. Never paste a password or token into chat or the repo.

5. Submit via the contest form

Choose the single-band .tif, paste the note, respect the weekly limit, and wait for processing.

6. Retain the receipt

Store the submission identifier, exact SHA-256, time, note and copied result. Only then label the result ORGANIZER-CONFIRMED.
