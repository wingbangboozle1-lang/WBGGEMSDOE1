How to submit WBG-6

Step 1. Download
wbg6-qmh-kdisjoint-30000-20261028.tif  (or wbg6-qmh-kdisjoint-30000-20261028.zip)

Step 2. Verify the bytes (optional, 10 s):

sha256sum wbg6-qmh-kdisjoint-30000-20261028.tif
# expected: e9111de909c6c9669baf71321539e2b30e742334a7dbc66c8ea021d5539401e9

Step 3 — BLOCKED. Do not upload. WBG-6 is on HOLD: the literal 3-px registry gate fails (see the gate decision). Upload is allowed only after the project owner chooses the gate and records approval. Upload page, for reference only: https://www.drivendata.org/competitions/306/competition-doe-gems/submissions/.

Note field (≤140 characters):
WBG-6 quantile-matched habitat, kernel-disjoint 30k dots, off-catalogue

What the portal checks, and what this file already satisfies

  • single-band float32 GeoTIFF — yes;
  • same CRS as the training data (EPSG:32611) — yes;
  • same shape and geotransform as the sample submission (3730 × 3292, 100 m, origin 243350 / 4508550) — yes;
  • values within [0, 1], no NaN inside the footprint, null/zero outside — yes (the historical "Predicted values must be in range [0, 1]" error came from a file that violated this; this one is validated byte-by-byte in evidence/wbg6_submission_audit.json);
  • a single GeoTIFF if you upload a ZIP — the ZIP contains exactly one member, identical to the TIFF.

Outside-footprint convention (corrected 28 Oct 2026)

The official rules say data outside the bounds is "null or nan". The pinned sample submission uses NaN for the 7,111,787 cells outside the footprint. The earlier zeros-outside file is still in the repo, but the recommended file is now wbg6-qmh-kdisjoint-30000-20261028-nan.tif, which has the same dots and NaN outside the footprint. The earlier claim that zeros was the only portal-accepted convention is withdrawn: user-reported scores exist for NaN-outside files too (GEMSDOE25 0.2600, GEMSDOE28 0.2708, GEMSDOE31 0.2708), and the 0.2778 file is also zeros-outside. Both conventions have user-reported scores. The cause of the "[0, 1]" portal error is still unverified.

Decision

DOWNLOAD: YES (review only) · SUBMIT: NOT CLEARED (HOLD). The file is format-valid and distinct from the nine sites (16–19% of each site's dots lie within 3 px of a WBG-6 dot). It fails the literal 3-px registry gate against r13 (99.68%; random in-footprint: 99.86%). The estimate of 0.247 is withdrawn as a decision number: it was a MODEL-ESTIMATE that the repo's own holdout could not validate. The leaderboard result is unknown.

This project does not upload anything and never asks for credentials. Weekly slot allowance is shown on the submissions page and must be checked there.
